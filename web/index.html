WAN Transport Floor

Cloud instances (Neo4j Aura and CognoDB Cloud) incur physical network latency (50ms - 240ms RTT) compared to in-process Unix domain sockets. The benchmark isolates this by measuring cold-start and local vs cloud baseline.

Deep Path Pruning

At 3-hop depth, dense subgraphs experience combinatorial explosion. Neo4j's planner pruned intermediate path states effectively (70.8ms), while scan-based engines experienced higher latency.

Hardware Parity (0.5 vCPU)

Every self-hosted database was strictly bounded to 0.5 vCPU and 256 MB RAM using Docker cgroups to ensure 100% fair evaluation against the free tier envelopes of managed cloud providers.
